# Bre McIlroy — Creative & Professional Portfolio

A static portfolio for the bre-mcilroy-portfolio GitHub Pages repository. No installation or build tools are needed.

Package: bre-mcilroy-portfolio.zip
Repository: https://github.com/bremcilroy-svg/bre-mcilroy-portfolio
Expected website address after successful deployment: https://bremcilroy-svg.github.io/bre-mcilroy-portfolio/

## Publish the update

1. Extract this ZIP on your phone or computer.
2. Open https://github.com/bremcilroy-svg/bre-mcilroy-portfolio and select the main branch.
3. Choose Add file (+) > Upload files. Select the extracted website files, including index.html, style.css, site.js, all other HTML pages, favicon.svg, and both images. Upload the files directly beside the existing index.html, rather than uploading the ZIP or adding a new enclosing folder.
4. Commit changes to main. Files with matching names will update; the new pages will be added.
5. Wait for the Pages deployment to finish, then visit https://bremcilroy-svg.github.io/bre-mcilroy-portfolio/ and refresh.

For the new repository, open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), and Save. If those settings are already configured, keep them. A new repository does not guarantee that a queued GitHub Actions job will start sooner. This ZIP contains website files only; deployment has not been performed here. GitHub's upload instructions: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
