# Amethyst Crescent Academy — Player Character Creator (Planning Notes)
Status: planned, not implemented. Keep the design extensible while the creator's remaining options are being decided.

## Height and proportions
- Height is an explicit character customization choice, not merely profile text.
- Headmaster Breezy is 5 feet 0 inches (152.4 cm) tall.
- Player characters should have a height selector with feet/inches and centimeters display.
- Visual height must affect relative character scale and eye level in scenes; avoid simply stretching character artwork.
- The supported range, proportions, age/body options, and gameplay camera rules are not decided yet. Ask before locking those in.
- Height is cosmetic: it must not prevent access to puzzles, clues, or rooms.
- Preserve accessible controls and ensure shorter/taller characters can interact with every puzzle.

## Player creator integration (future)
The academy grounds lead to the Grand Crescent Hall, where Headmaster Breezy welcomes visitors. Character creation should occur before the first puzzle room, with a way to revisit customization later. Do not add a mandatory creator gate until the user has chosen the complete design.
